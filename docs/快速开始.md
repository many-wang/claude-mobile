## 下一步操作

### 1. 后端开发

```bash
# 进入后端目录
cd C:\Users\HP\Desktop\claude-mobile\backend

# 安装依赖
npm install

# 复制环境变量文件
cp .env.example .env

# 编辑 .env 文件，填入你的 Claude API key
# ANTHROPIC_API_KEY=your_api_key_here

# 初始化数据库（创建表结构）
npm run init-db

# 启动开发服务器
npm run dev
```

后端将运行在 `http://localhost:3000`

### 2. 前端开发

```bash
# 新开一个终端，进入前端目录
cd C:\Users\HP\Desktop\claude-mobile\frontend

# 安装依赖
npm install

# 复制环境变量文件
cp .env.example .env

# 启动开发服务器
npm run dev
```

前端将运行在 `http://localhost:5173`

## 注意事项

1. **API Key 配置**
   - 必须在 `backend/.env` 中配置 `ANTHROPIC_API_KEY`
   - 不要将 `.env` 文件提交到 Git

2. **数据库位置**
   - SQLite 数据库将创建在 `backend/data/database.sqlite`
   - 首次运行需要执行 `npm run init-db` 初始化数据库

3. **端口占用**
   - 后端默认端口：3000
   - 前端默认端口：5173
   - 如果端口被占用，可以在 `.env` 中修改
