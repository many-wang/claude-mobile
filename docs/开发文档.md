# Claude 随身助手 - 开发文档

## 项目概述

**项目名称：** Claude 随身助手（轻量级移动版）

**核心功能：**
- 💬 与 Claude 对话聊天
- 📁 按项目/话题分类管理对话
- 💾 自动保存对话历史
- 📄 导出 Markdown 文档
- 🔍 搜索历史对话

**技术栈：**
- 前端：React + Vite + TailwindCSS (PWA)
- 后端：Node.js + Express
- 数据库：SQLite
- API：Claude API (Anthropic)
- 部署：Vercel

## 数据库设计

### 表结构

**1. projects（项目表）**
```sql
CREATE TABLE projects (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**2. conversations（对话表）**
```sql
CREATE TABLE conversations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id INTEGER,
    title TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);
```

**3. messages（消息表）**
```sql
CREATE TABLE messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    conversation_id INTEGER NOT NULL,
    role TEXT NOT NULL,  -- 'user' 或 'assistant'
    content TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (conversation_id) REFERENCES conversations(id)
);
```

## API 接口设计

### 后端接口

**基础路径：** `/api`

#### 1. 项目管理

**GET /api/projects**
- 功能：获取所有项目列表
- 返回：`{ projects: [...] }`

**POST /api/projects**
- 功能：创建新项目
- 参数：`{ name, description }`
- 返回：`{ project: {...} }`

**GET /api/projects/:id/conversations**
- 功能：获取项目下的所有对话
- 返回：`{ conversations: [...] }`

#### 2. 对话管理

**POST /api/conversations**
- 功能：创建新对话
- 参数：`{ project_id, title }`
- 返回：`{ conversation: {...} }`

**GET /api/conversations/:id**
- 功能：获取对话详情（包含所有消息）
- 返回：`{ conversation: {...}, messages: [...] }`

**POST /api/conversations/:id/messages**
- 功能：发送消息并获取 Claude 回复
- 参数：`{ content }`
- 返回：`{ userMessage: {...}, assistantMessage: {...} }`

**GET /api/conversations/:id/export**
- 功能：导出对话为 Markdown
- 返回：Markdown 文件内容

#### 3. 搜索

**GET /api/search?q=关键词**
- 功能：搜索对话内容
- 返回：`{ results: [...] }`
